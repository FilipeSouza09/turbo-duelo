# Turbo Duelo

Jogo de corrida 3D que roda direto no navegador.

- **Tela dividida:** dois jogadores no mesmo teclado (J1: W A S D, Shift, Espaço · J2: setas, Enter, Ctrl direito).
- **Online:** escolha *Online* no menu, crie uma sala e passe o código de 4 letras para até 3 amigos.
- **Gráficos:** se o jogo travar, escolha *Gráficos: Leve* no menu.

Tudo fica em um único arquivo, `index.html`. Usa three.js (r128) e PeerJS (MIT).
